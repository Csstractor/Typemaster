# Typemaster Keyboard Landing Page

A responsive landing page for a mechanical keyboard, built from a Figma design.

🌐Live Demo
You can view the live site here: 
https://cssractor.github.io/Typemaster/

## 🛠Technologies :

- HTML5
- CSS3 (Flexbox, Grid)
- Mobile-First approach
- GitHub Pages

## 💡What I learned :

- How to deploy a website using GitHub Pages.
- How to create responsive layouts using media queries and Flexbox.
- How to fix layout issues and handle browser caching.
